# NEXUS
Local: `npm i -g netlify-cli && cp .env.example .env` (llena las claves) → `netlify dev`
Deploy: sube la carpeta a GitHub y conéctala en Netlify, o `netlify deploy --prod`.
Variables: ver `.env.example`. Clave gratis: aistudio.google.com/apikey (GEMINI_API_KEY). Opcionales: Anthropic/OpenAI.
Voz (hablar/escuchar) usa el navegador: Chrome o Safari, sin claves.
Video: pendiente de proveedor (netlify/functions/video.js).
